# 🚦 湖興里交通熱點分析

監測台北市內湖區湖興里周邊幹道的即時車速,累積歷史資料後以簡單規則判斷是否為壅塞熱點,並附上制式改善建議。純前端小專案,不需要後端伺服器。

## 範圍與限制

- 涵蓋湖興里周邊 5 個 TDX 車輛偵測器(VD),位於成功路二段/三段、民權東路六段、金湖路——這些是里內聯外的主要幹道。
- **不涵蓋里內巷弄**:TDX 的車輛偵測器只佈設在主要幹道,住宅巷弄沒有偵測器覆蓋。
- 分析是**規則式**的(比較尖峰與離峰平均車速),不是專業交通工程模型,僅供參考討論。
- 需要連續運作數天以上,尖峰/離峰的資料才有統計意義;剛啟用時會顯示「資料收集中」。

## 運作方式

- GitHub Actions 每 30 分鐘呼叫一次 TDX `Road/Traffic/Live/VD`,取得 5 個路段的即時車速。
- 用「線上平均」的方式,把每筆讀數累加進對應的時段桶(平日/假日 × 0-23 時),只存加總與筆數,不存原始逐筆資料,因此檔案大小不會隨時間膨脹。
- 前端讀取這個累積結果,比較尖峰(早 7-9 / 晚 17-19)與離峰(晚間 22-1 時)平均車速,套用規則產生熱點標記與建議。
- TDX 金鑰只存在 GitHub Secrets,不會出現在任何前端程式碼。

## 執行方式

```bash
python3 -m http.server 8765
```

開啟 http://localhost:8765
